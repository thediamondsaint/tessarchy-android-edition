# GitHub field survey: Tessarchy Android Edition

Survey date: **2026-10-26**. Star counts below are the GitHub repository search counts captured on that date; they are snapshots, not quality scores. Each row is a separate implementation area. Where several useful projects appeared, they are ordered by stars within that area. This is a focused survey of public repositories, not a claim that every repository on GitHub was found.

## Star-ranked reference set

The clearest, mature Android launcher references found in the survey are [Lawnchair](https://github.com/LawnchairLauncher/lawnchair) (**13,786★**), [Kvaesitso](https://github.com/MM2-0/Kvaesitso) (**5,315★**), [Olauncher](https://github.com/tanujnotes/Olauncher) (**3,914★**), [KISS](https://github.com/Neamar/KISS) (**3,523★**), [OpenLauncher](https://github.com/OpenLauncherTeam/openlauncher) (**1,525★**), [Focus Launcher](https://github.com/mslalith/focus_launcher) (**265★**), and the Metro-specific [GridLauncher](https://github.com/Tgo1014/GridLauncher) (**112★**). General launcher popularity is much higher than direct Metro-launcher precedent; stars indicate attention, not code quality, maintenance, compatibility, or security.

## Survey method and reuse policy

The survey used 30 GitHub repository searches covering the areas above, sorted results by stars, then manually filtered obvious name/description matches that were not Android launcher implementations. Search results can miss repositories whose metadata uses different terms, and per-area queries are not an exhaustive crawl. Star counts and repository licenses can change; check the repository’s current `LICENSE` and the exact files before any future reuse.

TAE adopts the Apache-2.0 [Reorderable](https://github.com/Calvin-LL/Reorderable) library as a dependency. AndroidX Compose and DataStore are platform dependencies. Other repositories in this survey are references only; in particular, several top launcher projects use GPL licenses, and some projects have no identified license. TAE has not copied their code. The TAE repository itself has no selected project license yet, so public visibility should not be read as a grant to reuse TAE source.
